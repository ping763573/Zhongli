保險規劃核心原則

保險的根本價值在於作為財務安全網，核心功能是轉嫁個人或家庭無法承受的災難性財務風險。

🎯 黃金公式：已備保額 ≈ 應備保額

情況 已備保額與應備保額 財務風險
理想狀態 已備 ≈ 應備 ✓ 低風險、合理規劃
過度保險 已備 > 應備 ⚠️ 資源浪費
保障不足 已備 < 應備 ✗ 高風險

📈 建議保險規劃順序

階段一：基礎保障
• 壽險（定期）
• 醫療險（實支實付）
• 意外險
階段二：強化保障
• 防癌險
• 重大傷病險
• 長期照護險

定期險 VS 終身險

在確定應備保額後，選擇合適的產品結構是下一步決策

📊 詳細比較表

特性 終身險 定期險
保障期間 長期穩定（99～110歲） 特定期間（75～85歲）
費率結構 平準費率（固定不變） 自然費率（隨年齡遞增）
保費（同保額） 較高（約2～8倍） 較低
保障槓桿（同保費） 較低 較高（約2～8倍）
財務彈性 較低 較高

🎯 BTID策略（定期險取代終身險）

用定期險的低保費搭配投資，作為退休後的醫療與長照基金

⚠️ BTID成功的5大先決條件：
1️⃣ 高度資產管理能力
2️⃣ 長期投資知識
3️⃣ 專業協助與信任
4️⃣ 體況風險認知
5️⃣ 退休基金準備充足

💡 選擇建議

✓ 選定期險若您：

• 退休前責任最重
• 資產管理能力強
• 追求高保障槓桿
• 有投資規劃

✓ 選終身險若您：

• 希望長期穩定保障
• 資產已相當充足
• 不願自行投資
• 偏好定額支出

核心保障配置策略

科學的保障順序確保有限的預算先覆蓋最核心、影響最大的風險

🏗️ 階段一：基礎保障（建立防線）

💼 壽險
保額：應備保額缺口
形式：定期壽險（家庭責任重時）
目的：填補收入中斷風險
🏥 醫療險
保額：20萬/次以上
形式：實支實付
目的：填平高額住院雜費
🚨 意外險
保額：視家庭需求
形式：日常意外事故保險
目的：補充身故或失能保障

⭐ 階段二：重點強化保障

🔬 重大傷病險(CI/CD)
保額：1～3年收入合計
特點：一次性給付
用途：支撐黃金治療期支出
🏥 長期照護險
保額：36萬/年
風險：高齡生理或認知衰退
特點：長期、高額費用
🩹 失能扶助險
保額：30萬/年
覆蓋：工作階段失能
功能：收入替代
🎗️ 防癌險
日額：2,000元/日
手術/門診：5萬/次
針對：國人常見疾病

📊 醫療風險量化原則

項目 建議額度 計算基礎
住院日額 4,000元/日 看護費2千 + 薪資損失3千 - 勞保1千

保單稅務與資產傳承規劃

人壽保險的身故保險金具有特殊的法律與稅務優勢，但須嚴格遵循規範

⚖️ 法律特殊性與傳承優勢

保險法第112條：有指定受益人的死亡保險金不計入被保險人遺產
1️⃣ 預留稅源
死亡保險金可在繳納遺產稅前迅速領到，提供流動資金支付稅款
2️⃣ 對抗特留分
指定受益人機制類似遺囑，不受應繼分與特留分限制
3️⃣ 受益權獨立性
受益人可拋棄繼承遺產，但仍可領取身故保險金

🏛️ 保單關係人配置與稅務風險

要保人(P)、被保險人(I)、受益人(B) 的配置直接影響稅務結果

要保人 被保險人 受益人 遺產稅 贈與稅 最低稅負
父 父 子 ✗ ✗ ✓
父 子 父 ✗ ✗ ✗
子 父 子 ✗ ✗ ✗
子 父 母 ✗ ✓ ✓
子 子 父 ✗ ✗ ✓
💡 核心原則：採取「P=I」（要保人與被保險人同一人）的設定，能最簡化稅務結構

⚠️ 實質課稅原則的防範

國稅局可依實質課稅原則，以實質經濟利益判斷課稅標準

關鍵：購買保險的目的必須是風險保障，非單純資產移轉。否則保險金將被視為遺產課稅。

🚨 國稅局認定「避稅」的8大常見態樣

1️⃣ 高齡投保
投保年齡已超過70歲
2️⃣ 躉繳保費
一次性繳交大筆現金
3️⃣ 短期投保
身故發生在投保後短期內
4️⃣ 密集投保
短期間內密集投保多張
5️⃣ 舉債投保
向銀行貸款購買保單
6️⃣ 帶病投保
健康狀況極差時投保
7️⃣ 鉅額投保
保額明顯超出收入資產
8️⃣ 資金流動異常
保費來源不符正常收入
